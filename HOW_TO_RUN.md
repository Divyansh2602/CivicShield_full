# CivicShield AI — How to Run & Demo

A quick, reliable guide to start both servers and walk your teacher through the
whole product. Two terminals: one for the backend, one for the frontend.

---

## 0. Prerequisites (install once)

- **Node.js 18+** — <https://nodejs.org>
- **Python 3.10+** — <https://python.org>

Check they're installed:

```bash
node -v
python --version
```

---

## 1. Start the backend (Terminal 1)

```bash
cd backend
pip install -r requirements.txt          # first time only

# (Only if backend/ml/phishing_model.pkl is missing)
python ml/train_phishing_model.py

python seed_db.py                          # loads a demo scan so the dashboard has data
python main.py                             # starts the API on http://127.0.0.1:8000
```

You should see `Phishing model warmed up` and `Uvicorn running on http://127.0.0.1:8000`.
Note the **scan id** printed by `seed_db.py` (e.g. `Seeded demo scan id=8 …`).

> Check it works: open <http://127.0.0.1:8000/health> — you should see `{"status":"healthy",…}`.
> API docs (bonus to show): <http://127.0.0.1:8000/docs>

---

## 2. Start the frontend (Terminal 2)

```bash
cd frontend
npm install                                # first time only
npm run dev                                # starts the site on http://localhost:3000
```

`frontend/.env.local` should contain `BACKEND_URL=http://localhost:8000` (already set).

Open **<http://localhost:3000>** in Chrome.

---

## 3. Demo script (≈3 minutes)

1. **Landing page** — <http://localhost:3000>
   - Point out the hero: *"Acquire the target. Map the exposure."*
   - Click into the **target box** → the mint targeting-reticle brackets lock in
     (the "acquire target" moment). Scroll to show the scan pipeline + capabilities.

2. **Live dashboard (pre-seeded)** — open
   <http://localhost:3000/dashboard?scanId=8>
   - **Threat Index** instrument gauge, severity metric cards, **AI Threat Insights**
     (live rotating), trend + distribution charts, the **3D threat globe**, and the
     **vulnerability table** (click a row to reveal the payload & evidence).
   - Click **Download Report** → a real PDF is generated by the backend.

3. **Walk the modules** (all share the same `?scanId=8` context):
   - **Attack Surface** — force-graph of discovered routes, risk-tagged.
   - **API Security** — endpoint inventory + auth posture.
   - **Phishing Detection** — paste a URL (e.g. `http://paypal-verify-login.tk/confirm`)
     → live ML score + explainable features.
   - **Activity Logs**, **Reports**, **Settings** — all consistent and polished.

4. **Run a real scan (optional, needs internet):**
   - On the landing page, enter a site **you own or are authorized to test**
     (e.g. `testphp.vulnweb.com`, a public test target) → click **Begin scan** →
     it routes to the live dashboard and polls until complete.

## 4. Talking points (what makes it strong)

**Engineering / security (backend)**
- **SSRF protection** — the scanner refuses private/loopback/cloud-metadata targets.
  *Demo:* try scanning `http://localhost:8000` on the landing page → it's blocked.
- **Rate limiting, JWT auth, security headers, env-based secrets** — production hardened.
- **Database-backed** scan state (survives restarts), background scanning, PDF reports.
- **Cold-start keep-warm** — `/health` + model preload + optional self-ping.

**Frontend / performance**
- Custom design system: Bebas Neue + DM Sans + JetBrains Mono, one cohesive theme
  across every page.
- **Largest Contentful Paint optimized to ~142 ms** (was ~950 ms) — verified with
  Chrome DevTools; stays fast even on throttled 3G.

## 5. Troubleshooting

| Symptom | Fix |
|---|---|
| Dashboard empty / "No target acquired" | Make sure you used `?scanId=8` (or the id `seed_db.py` printed), and the backend is running. |
| Scan of a real site returns 0 findings | The target may block scanners or be unreachable; use the seeded demo (`scanId=8`) for a guaranteed populated view. |
| Want to scan a **local** app | In `backend/.env` set `ALLOW_PRIVATE_TARGETS=true`, then restart the backend. |
| Port already in use | Close old `python`/`node` processes, or change the port. |
| Phishing returns 503 | Run `python ml/train_phishing_model.py`, then restart the backend. |
